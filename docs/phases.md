# Delivery phases

Every phase follows the Git workflow in [CLAUDE.md](../CLAUDE.md#git-workflow-mandatory-every-phase): preflight, then the `phase-<N>-<name>` branch, then a PR. The owner reviews and merges. A phase may not start until the previous phase branch is merged into `origin/main`.

**Global definition of done (every phase):** lint, typecheck and format pass; both apps start; RLS reviewed for any new table; no secrets in the diff; docs updated; PR opened with screenshots where there is UI.
